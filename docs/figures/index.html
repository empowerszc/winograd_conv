00一句话

同一个算法，两种工程哲学；差异全部落在工程实现上，并且每一条都有可复现的数据。

本项目从 ACL 的 Winograd 思路出发，算法与变换矩阵完全一致；差异在四处工程选择： 固定 F(4,4) 主路径而不按形状降级、泛型 SVE 内核而不手写展开汇编、可插拔 GEMM 后端而不绑定单一库、 单 OpenMP 区域而不引入调度器。

为什么强调绑核：不绑核时 t16 的 SME 合计会在 387–558 ms 之间漂移，结论直接翻转成「SME 慢 2 倍」； 绑核后两次重复差异 < 2.5%。同理，集群跨作业存在 3–7x 的性能态漂移，因此所有对比都在单作业内完成。
