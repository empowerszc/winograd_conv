04并行结构：一次 fork/join

权重变换 + 所有 batch 的输入/GEMM/输出都在同一个 parallel 区域内，靠显式 barrier 串起三段。

05缓冲与缓存：热路径不做分配

线程本地缓冲

6 个 thread_local 缓冲（d/U/M/f tile、权重临时）跨调用复用， 容量不足才 realloc。每个逻辑缓冲持有独立的 Scratch —— 早期共用一个曾导致 9 个缓冲全部别名同一块内存， 正确性测试全挂。

V 跨调用缓存

key = 权重指针 + 64 点 FNV-1a 指纹 + shape + F44 标记 + ISA，防「同址重分配」的 ABA。 命中直接跳过权重变换，KML t16 几何平均 1.07x、最高 1.74x。 容量 24 条且无淘汰是个已知短板（59 形状用例集后半段不命中）。
