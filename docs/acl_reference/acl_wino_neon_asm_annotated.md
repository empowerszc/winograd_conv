## 1. 数学背景

### 1.1 Winograd 输入变换公式

输入变换计算 `U = B^T · d · B`，其中：
- `d` 是 6×6 输入 tile（从特征图中提取，含 padding）
- `B` 是 6×6 变换矩阵
- `U` 是 6×6 Winograd 域结果

### 1.2 B 矩阵（ACL 使用的整数缩放版）

ACL 使用整数系数的 B 矩阵，避免浮点除法。pcoeffs = `{1.0, 2.0, 4.0, 5.0}` 是缩放因子：

```
B^T 的实际形式（从代码逆推）：

B^T = [1    0    0    0    0    0  ]   ← 行 0: 直接取 d[0]
      [0    1   -1    1   -1    0  ]   ← 行 1: 交错 ±1
      [0    1    1    1    1    0  ]   ← 行 2: 全 +1
      [0   -2    0    2    0    0  ]   ← 行 3: ±2
      [0   -1    1   -1    1    0  ]   ← 行 4: 交错 ∓1（反向）
      [0    0    0    0    0    1  ]   ← 行 5: 直接取 d[5]
```

但汇编不直接用这个矩阵。它用一个 **两步分解** + **缩放优化**：

1. 先计算中间量（如 `d[1]-d[2]`, `d[1]+d[2]` 等）
2. 再用 `fmad z = z*4 + x`（乘 4 加）和 `fmla z += x*coef`（乘系数加）组合出最终结果
3. pcoeffs 作为 `v0.s[0..3]` 逐元素索引使用

### 1.3 两步分解

2D 变换 `U = B^T · d · B` 分解为：
1. **列变换**: `T[i][j] = Σ_k B^T[i][k] · d[k][j]`（对每列 j 做矩阵-向量乘）
2. **行变换**: `U[i][j] = Σ_k T[i][k] · B[k][j]`（对每行 i 做矩阵-向量乘）

汇编将两步**交错执行**：先算完一组列变换，立即做行变换，减少中间存储。

## 2. 整体结构：三层降级

| 层级 | 行号 | 寄存器 | 通道数/迭代 | 触发条件 |
|------|------|--------|------------|---------|
| 4-通道 | 65-416 | Q (128-bit, 4 float) | 4 | `n_channels >= 4` |
| 2-通道 | 417-768 | D (64-bit, 2 float) | 2 | `n_channels >= 2` |
| 1-通道 | 769-1118 | S (32-bit, 1 float) | 1 | 剩余 |

**降级策略**：NEON 没有 SVE 的谓词掩码，无法在一条指令中处理"不足一个向量宽度"的尾部。
ACL 的方案是写三份完全展开的代码，分别处理 4/2/1 个通道。

## 3. 寄存器分配

### 3.1 4-通道层（Q 寄存器）

```
v0     = pcoeffs [1.0, 2.0, 4.0, 5.0]（只读，通过 v0.s[idx] 按元素索引）
v1-v31 = 工作寄存器（存输入数据、中间结果、输出结果）

输入指针:
  inptr0  → 输入行 0 (d[0][0..5])
  x25     → 输入行 1 (d[1][0..5])
  x16     → 输入行 2 (d[2][0..5])
  x17     → 输入行 3 (d[3][0..5])
  x26     → 输入行 4 (d[4][0..5])
  x27     → 输入行 5 (d[5][0..5])

输出指针:
  outptr0 → 输出行 0 (U[0][0..5])
  x28     → 输出行 1 (U[1][0..5])
  x22     → 输出行 2 (U[2][0..5])
  x12     → 输出行 3 (U[3][0..5])
  x14     → 输出行 4 (U[4][0..5])
  x24     → 输出行 5 (U[5][0..5])

列偏移:
  x10 = 2 * input_col_stride  (列 2)
  x8  = 3 * input_col_stride  (列 3)
  x20 = 4 * input_col_stride  (列 4)
  x21 = 5 * input_col_stride  (列 5)
  input_col_stride1 = 1 * input_col_stride (列 1)
```

### 3.2 数据加载模式

6×6 tile 的 36 个元素通过 6 个行指针 × 6 个列偏移加载：

```
d[i][j] = ldr q, [ptr_row_i, offset_col_j]
```

每个 `ldr q` 加载 4 个 float（4 个通道）。

## 4. 4-通道层逐行注释（行 43-416）

### 4.1 初始化（行 42-64）

```asm
// 行 42: 缩放系数
const float pcoeffs[4] = {1.0f, 2.0f, 4.0f, 5.0f};

// 行 43: 进入内联汇编
__asm__ __volatile__(

// 行 44: 加载 pcoeffs 到 v0（Q 寄存器，4 个 float）
"ldr q0, [%[pcoeffs]]\n"
// v0 = [1.0, 2.0, 4.0, 5.0]，后续通过 v0.s[0]=1, v0.s[1]=2, v0.s[2]=4, v0.s[3]=5 访问

// 行 45-62: 设置 6 个输入行指针和 6 个输出行指针
"add x25, %[inptr0], %[input_row_stride]\n"
// x25 = input_base + 1*row_stride → 行 1

"add x10, %[input_col_stride1], %[input_col_stride1]\n"
// x10 = 2 * col_stride → 列 2 的偏移

"add x16, x25, %[input_row_stride]\n"
// x16 = input_base + 2*row_stride → 行 2

// ... 依次设置 x17=行3, x26=行4, x27=行5
// ... 依次设置输出指针 x28=行1, x22=行2, x12=行3, x14=行4, x24=行5
// ... 依次设置列偏移 x8=3*cs, x20=4*cs, x21=5*cs

// 行 63-64: 检查通道数，决定走哪个层级
"cmp %w[n_channels], #4\n"   // 通道数 >= 4？
"blt 2f\n"                    // 不够 4，跳到 2-通道层
```

### 4.2 4-通道循环体——第一组行（行 65-176）

这一段处理输入行 0-2 的数据，计算列变换 B^T·d 的前 3 行，并立即做行变换得到 U[0][0..5]。

```asm
"1:\n"  // 4-通道循环开始

// === 加载输入行 0 的 6 个元素 ===
// d[0][4], d[0][2], d[0][0], d[0][5], d[0][3], d[0][1]
"ldr q8, [%[inptr0], x20]\n"    // v8  = d[0][4] (列 4)
"ldr q2, [%[inptr0], x10]\n"    // v2  = d[0][2] (列 2)
"ldr q9, [%[inptr0]]\n"         // v9  = d[0][0] (列 0)
"ldr q1, [%[inptr0], x21]\n"    // v1  = d[0][5] (列 5)
"ldr q4, [%[inptr0], x8]\n"     // v4  = d[0][3] (列 3)
"ldr q12, [%[inptr0], %[input_col_stride1]]\n"  // v12 = d[0][1] (列 1)

// === 列变换：计算 B^T·d 的行 0 的中间量 ===
// 目标：U[0][j] = B^T[0]·d·B[j] = d[0]·B[j]（因为 B^T[0]=[1,0,0,0,0,0]）
// 但 ACL 用缩放版，需要更复杂的计算

// v14 = v8 (copy d[0][4])，然后累加
"mov v14.16b, v8.16b\n"         // v14 = d[0][4]
"fmla v14.4s, v9.4s, v0.s[2]\n" // v14 += d[0][0] * 4  → v14 = 4*d[0][0] + d[0][4]

// v10 = v8 (copy d[0][4])，然后减
"mov v10.16b, v8.16b\n"
"fmls v10.4s, v12.4s, v0.s[2]\n" // v10 -= d[0][1] * 4

// v9 继续：v9 += d[0][1] * 4
"mov v9.16b, v8.16b\n"          // 等等，v9 被覆盖了？
// 注意：这里 v9 被重新赋值为 d[0][4]，但原始 v9=d[0][0] 的值已经在 v14 中用了
"fmla v9.4s, v12.4s, v0.s[2]\n" // v9 = d[0][4] + 4*d[0][1]

// v14 继续累减
"fmls v14.4s, v2.4s, v0.s[3]\n" // v14 -= d[0][2] * 5
// → v14 = 4*d[0][0] + d[0][4] - 5*d[0][2]

// v10 继续累减
"fmls v10.4s, v2.4s, v0.s[2]\n" // v10 -= d[0][2] * 4
"fadd v10.4s, v10.4s, v4.4s\n"  // v10 += d[0][3]
// → v10 = d[0][4] - 4*d[0][1] - 4*d[0][2] + d[0][3]

// v9 继续累减
"fmls v9.4s, v2.4s, v0.s[2]\n"  // v9 -= d[0][2] * 4
"fsub v9.4s, v9.4s, v4.4s\n"    // v9 -= d[0][3]
// → v9 = d[0][4] + 4*d[0][1] - 4*d[0][2] - d[0][3]

// === 行变换：从中间量组合出 U[0][0..5] ===
// U[0][j] = Σ_k intermediate[k] * B[k][j]
// 这里的 intermediate 就是 v14, v10, v9 等中间量

"mov v7.16b, v8.16b\n"          // v7 = d[0][4]
"fmls v7.4s, v12.4s, v0.s[1]\n" // v7 -= d[0][1] * 2
// → v7 = d[0][4] - 2*d[0][1]
"fsub v7.4s, v7.4s, v2.4s\n"    // v7 -= d[0][2]
"fmla v7.4s, v4.4s, v0.s[1]\n"  // v7 += d[0][3] * 2
// → v7 = d[0][4] - 2*d[0][1] - d[0][2] + 2*d[0][3]

"mov v8.16b, v8.16b\n"          // v8 = d[0][4]（保持）
"fmla v8.4s, v12.4s, v0.s[1]\n" // v8 += d[0][1] * 2
"fsub v8.4s, v8.4s, v2.4s\n"    // v8 -= d[0][2]
"fmls v8.4s, v4.4s, v0.s[1]\n"  // v8 -= d[0][3] * 2
// → v8 = d[0][4] + 2*d[0][1] - d[0][2] - 2*d[0][3]

// === 类似地处理输入行 1 (x16 指针) ===
"ldr q5, [x16, x20]\n"     // v5  = d[2][4]
"ldr q20, [x16, x10]\n"    // v20 = d[2][2]
"ldr q3, [x16]\n"          // v3  = d[2][0]
"ldr q6, [x16, x21]\n"     // v6  = d[2][5]
"ldr q16, [x16, x8]\n"     // v16 = d[2][3]
"ldr q22, [x16, %[input_col_stride1]]\n" // v22 = d[2][1]

// v1 = d[0][5], 做 B^T 行 1 变换
"fmla v11.4s, v12.4s, v0.s[2]\n" // v11(=v1=d[0][5]) += d[0][1]*4
"fmls v11.4s, v4.4s, v0.s[3]\n" // v11 -= d[0][3]*5

// v1(v5) 做 B^T 行 2 变换
"fmla v1.4s, v3.4s, v0.s[2]\n"  // v1 += d[2][0]*4
"fmls v1.4s, v20.4s, v0.s[3]\n" // v1 -= d[2][2]*5

// ... 类似的模式继续处理每一行

// === 行变换完成，存储 U[0][0..5] ===
"str q23, [%[outptr0]]\n"                        // U[0][0]
"str q15, [%[outptr0], %[output_col_stride1]]\n" // U[0][1]
"str q14, [%[outptr0], x11]\n"                    // U[0][2]
"str q24, [%[outptr0], x13]\n"                    // U[0][3]
"str q10, [%[outptr0], x23]\n"                    // U[0][4]
"str q7, [%[outptr0], x15]\n"                     // U[0][5]
```

### 4.3 4-通道循环体——第二组行（行 180-416）

用相同模式处理输入行 3-5（x25, x26, x27 指针），计算 U[1][0..5] 到 U[5][0..5]。

关键模式：
```
// 加载 6 个输入元素
ldr qN, [row_ptr, col_offset]

// 列变换：fmla/fmls 用 v0.s[idx] 做系数
fmla vDst, vSrc, v0.s[0]  // += src * 1.0
fmls vDst, vSrc, v0.s[1]  // -= src * 2.0
fmla vDst, vSrc, v0.s[2]  // += src * 4.0
fmls vDst, vSrc, v0.s[3]  // -= src * 5.0

// 行变换：fadd/fsub 做加减（系数 1）
fadd vDst, vA, vB   // += B
fsub vDst, vA, vB   // -= B

// 存储
str qN, [out_ptr, col_offset]
```

## 5. 2-通道层逐行注释（行 417-768）

### 5.1 结构

与 4-通道层完全相同的算法，但使用 64-bit D 寄存器（`vN.d[0]`）。
每条指令处理 2 个 float 而非 4 个。

```asm
"2:\n"                          // 2-通道层入口
"cmp %w[n_channels], #2\n"      // 通道数 >= 2？
"blt 3f\n"                       // 不够 2，跳到 1-通道层

// 使用 d 寄存器（64-bit，2 float）
"ldr d8, [%[inptr0], x20]\n"    // 加载 2 个通道
// ... 同样的 fmla/fmls/fadd/fsub 模式
// ... 但用 .2s 而非 .4s 后缀
```

### 5.2 关键差异

| 方面 | 4-通道层 | 2-通道层 |
|------|---------|---------|
| 寄存器 | Q (128-bit) | D (64-bit) |
| 后缀 | `.4s` | `.2s` |
| 指针步进 | `#16` (16 bytes) | `#8` (8 bytes) |
| 每迭代通道 | 4 | 2 |

### 6.1 结构

使用 32-bit S 寄存器（标量），每条指令处理 1 个 float。

| 方面 | 4-通道层 | 1-通道层 |

| 指针步进 | `#16` | `#4` |
| 指令后缀 | `.4s` | 无（标量） |

## 7. 优化技术总结

### 7.1 三层降级（Tail Handling）

**问题**：NEON Q 寄存器固定 128-bit（4 float），当通道数不是 4 的倍数时，多余的数据怎么处理？

**ACL 方案**：写三份完全展开的代码，分别处理 4/2/1 通道。

```
if (n_channels >= 4) → Q 寄存器循环
else if (n_channels >= 2) → D 寄存器循环
else → S 寄存器循环
```

**对比 SVE**：SVE 用 `whilelt` 谓词掩码自动处理尾部，只需一份代码。

### 7.2 指令调度（Instruction Scheduling）

汇编中的指令顺序**不是**"先加载所有数据，再计算，最后存储"。
而是**交错**：加载 → 计算 → 加载 → 计算 → 存储 → 加载...

例如行 66-100：
```
ldr q8     // 加载 d[0][4]
ldr q2     // 加载 d[0][2]
mov v14    // 复制（不访存）
ldr q9     // 加载 d[0][0]
fmla v14   // 计算（用已加载的数据）
ldr q4     // 加载 d[0][3]  ← 计算和加载并行
fmls v10   // 计算
ldr q12    // 加载 d[0][1]  ← 再次交错
```

**目的**：利用 AArch64 的乱序执行能力，让加载指令的延迟与计算指令重叠。

### 7.3 寄存器复用

Q 寄存器只有 32 个（v0-v31），但 6×6=36 个输入元素 + 中间结果 + 输出结果远超 32。

ACL 的策略：
1. **及时覆盖**：数据用完后立即复用寄存器存新数据
2. **mov 复制**：需要保留的值通过 `mov vN.16b, vM.16b` 复制到另一个寄存器
3. **分批处理**：先处理行 0-2（存 U[0][*]），再处理行 3-5（存 U[3][*]）

### 7.4 系数向量复用

`pcoeffs = {1.0, 2.0, 4.0, 5.0}` 只加载一次到 `v0`，后续通过 `v0.s[0]`、`v0.s[1]`、`v0.s[2]`、`v0.s[3]` 按元素索引反复使用。

**优势**：
- 1 次 `ldr q0` 替代 4 次 `fmov` 立即数加载
- `fmla vD, vS, v0.s[2]` 是 AArch64 的 by-element FMLA，单周期发射

### 7.5 循环完全展开

4-通道层的循环体处理**所有 6 行 × 6 列 = 36 个元素**，没有任何内层循环。
全部展开为直线代码，消除分支开销。

### 7.6 软件流水（Software Pipelining）

在循环回跳前（行 360-376），提前加载下一轮的数据：

```asm
// 存储当前轮的最后一个输出
"str q17, [x14, x15]\n"

// 立即开始加载下一轮的第一个输入
"ldr q2, [x27, x20]\n"     // d[5][4]（下一轮）
"ldr q17, [x27, x10]\n"    // d[5][2]
"ldr q18, [x27]\n"         // d[5][0]
// ... 继续加载
// 最后检查循环条件并回跳
"cmp %w[n_channels], #4\n"
"b.ge 1b\n"
```

这样在回跳时，下一轮的部分数据已经在寄存器中，减少循环迭代间的延迟。

## 8. 与 C++ NEON Intrinsic 版的对比

ACL 的 `arm_fp32_4x4.cpp`（F(2,2,3,3) 输入变换）用 C++ intrinsics 实现了相同算法：

| 方面 | C++ Intrinsic (`arm_fp32_4x4.cpp`) | 内联汇编 (`a64_fp32_6x6.cpp`) |
|------|------|------|
| 矩阵大小 | 4×4 (F(2,2)) | 6×6 (F(4,4)) |
| 代码量 | 251 行 | 1140 行 |
| 可读性 | 高（变量名、注释） | 低（只有寄存器号） |
| 指令调度 | 编译器决定 | 手动优化 |
| 寄存器分配 | 编译器决定 | 手动分配 |
| 软件流水 | 无 | 有（循环回跳前预加载） |
| 三层降级 | 有（4/2/1 通道） | 有（4/2/1 通道） |
| 系数复用 | `vmlaq_n_f32`（立即数） | `v0.s[idx]`（by-element） |

**关键差异**：内联汇编版通过手动指令调度和软件流水获得额外 ~5-10% 性能，
但代价是代码量 4.5 倍增长和可维护性大幅下降。

## 9. 输出变换和权重变换的 NEON Intrinsic 版

ACL 的输出变换（`arm_fp32_4x4_3x3.cpp`、`arm_fp32_2x2_3x3.cpp`）和权重变换
（`arm_fp32_4x4_3x3.cpp`、`arm_fp32_2x2_3x3.cpp`）使用 C++ intrinsics，不是内联汇编。

这些文件的注释已经在源码中很清晰（每行公式都有 `//` 注释），
无需额外文档。核心模式：

### 9.1 输出变换（F(4,4,3,3)）

```cpp
// f = A^T · (A^T · M)^T = Z^T · FZ
// 其中 Z = A^T 的行向量

// 第一步：FZ = F · Z（行变换）
FZ[i][0] = F[i][0] + F[i][1] + F[i][2] + F[i][3] + F[i][4];
FZ[i][1] = (F[i][1] - F[i][2]) + 2*(F[i][3] - F[i][4]);
FZ[i][2] = (F[i][1] + F[i][2]) + 4*(F[i][3] + F[i][4]);
FZ[i][3] = (F[i][1] - F[i][2]) + 8*(F[i][3] - F[i][4]) + F[i][5];

// 第二步：f = Z^T · FZ（列变换，相同系数）
f[0][j] = FZ[0][j] + FZ[1][j] + FZ[2][j] + FZ[3][j] + FZ[4][j];
f[1][j] = (FZ[1][j] - FZ[2][j]) + 2*(FZ[3][j] - FZ[4][j]);
f[2][j] = (FZ[1][j] + FZ[2][j]) + 4*(FZ[3][j] + FZ[4][j]);
f[3][j] = (FZ[1][j] - FZ[2][j]) + 8*(FZ[3][j] - FZ[4][j]) + FZ[5][j];
```

### 9.2 权重变换（F(4,4,3,3)）

```cpp
// V = G · g · G^T / 576
// G 用整数系数（最大 24），最后除以 24²=576

// 第一步：Ww = G · g（行变换）
Ww[0][j] =  6 * w[0][j];
Ww[1][j] = -4 * (w[0][j] + w[1][j] + w[2][j]);
Ww[2][j] =  4 * (w[1][j] - w[0][j] - w[2][j]);
Ww[3][j] = w[0][j] + 2*w[1][j] + 4*w[2][j];
Ww[4][j] = w[0][j] - 2*w[1][j] + 4*w[2][j];
Ww[5][j] = 24 * w[2][j];

// 第二步：V = Ww · G^T / 576（列变换，相同系数）
V[i][0] =  6 * Ww[i][0] / 576;
V[i][1] = -4 * (Ww[i][0] + Ww[i][1] + Ww[i][2]) / 576;
// ... 同样模式
```

F(2,2,3,3) 的 B^T（输入变换矩阵）：
